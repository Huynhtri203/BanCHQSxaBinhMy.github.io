HƯỚNG DẪN KẾT NỐI GOOGLE SHEETS

1
Tạo Google Sheets mới và đặt tiêu đề hàng đầu tiên gồm các cột theo thứ tự:
so_quyet_dinh ho_ten cccd ngay_sinh don_vi_cu don_vi_moi chuc_vu ngay_quyet_dinh hieu_luc pdf_url ghi_chu
2
Publish to web: Vào File → Share → Publish to web, chọn Sheet1, format CSV, bấm Publish. Copy link CSV.
3
Lấy Sheet ID từ URL Google Sheets — đoạn ký tự dài nằm giữa /d/ và /edit — rồi điền vào biến SHEET_ID trong phần <script> cuối file HTML này.
4
Upload PDF lên Google Drive: Upload file → chuột phải → Get link → chọn "Anyone with the link". Lấy FILE_ID từ link rồi tạo URL dạng:
https://drive.google.com/file/d/FILE_ID/preview
Điền URL này vào cột pdf_url trong Google Sheets.
5
Đổi mật khẩu admin: Tìm biến ADMIN_USER và ADMIN_PASS trong script để đặt tài khoản riêng. (Xác thực client-side — chỉ phù hợp mạng nội bộ hoặc Intranet)
6
Ghi dữ liệu từ web (nâng cao): Tạo Google Apps Script Web App để nhận POST request và ghi vào Sheets. Điền URL vào biến GAS_URL. Nếu để trống, Admin cần nhập liệu trực tiếp vào Google Sheets.
